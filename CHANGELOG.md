# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and the project intends to use Semantic Versioning once stable public interfaces are established.

## [Unreleased]

## [0.1.1] - 2026-09-17

### Added

- Cross-platform GitHub Actions test matrix for Python 3.11 and 3.12.
- CodeQL analysis and Dependabot configuration.
- Structured bug reports, feature requests, and pull request checklist.
- Security, support, contribution, maintainer, roadmap, and third-party license documentation.
- Automated source archive and checksum creation for version tags.
- English project documentation.

## [0.1.0] - 2026-07-24

### Added

- Local Gradio interface for converting MP4/MOV video to relative-depth MP4.
- Depth Anything V2 Small, Base, and Large model choices.
- CUDA, Apple MPS, and CPU execution paths.
- Original, 480p, 720p, and 1080p output presets.
- Robust percentile normalization and EMA temporal smoothing.
- Optional depth inversion and source-audio preservation.
- H.264 `yuv420p` fast-start output.
- Progress reporting, estimated time remaining, and cancellation.
- Tests that use a deterministic fake depth provider.
- Installable Codex Skill and cross-platform launcher.
