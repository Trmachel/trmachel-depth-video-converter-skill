# Support

## Installation or conversion problem

Open a **Bug report** and include the operating system, Python version, compute mode, selected model, input container, reproduction steps, and relevant redacted logs.

## Feature idea

Open a **Feature request** and describe the workflow problem before the implementation you prefer.

## Security issue

Follow [SECURITY.md](SECURITY.md) and report privately. Do not disclose exploit details in a public issue.

## Media and privacy

Do not upload private, sensitive, or unlicensed video. A short synthetic clip that reproduces the issue is preferred.

Support is provided on a best-effort basis by the project maintainer.
